# Lazy Gamer store submission checklist

**The owner must verify current store policies and applicable child-data laws before submitting.** This checklist was prepared on 18 November 2026. Check the consoles again on submission day.

## Build and try the app

1. Install the project’s Node dependencies with `npm ci`, then run `npm run native:sync` from the repository root. This bundles the game, sound, fonts and art, and copies the bundle into both native projects.
2. On Android, install JDK 21 and the Android 16 SDK. In `android/`, run `./gradlew :app:assembleDebug` for a test APK. The candidate app ID is `com.aashidani.lazygamer`. Confirm it before creating store records. Create a signed release App Bundle with Android Studio before uploading. Protect and back up your upload key. [Target API requirements](https://support.google.com/googleplay/android-developer/answer/11926878), [Android app signing](https://developer.android.com/studio/publish/app-signing)
3. On a Mac with full Xcode, open `ios/App/App.xcodeproj` or run `npx cap open ios`. Select your signing team, use the registered bundle ID, let Xcode resolve the Swift packages, then build on both an iPhone and an iPad. For distribution, archive in Xcode and use TestFlight. Verify the current SDK minimum before upload. [Apple SDK requirements](https://developer.apple.com/news/upcoming-requirements/), [TestFlight](https://developer.apple.com/testflight/)
4. Try a fresh install in airplane mode. Open a town, sell stock, leave and reopen the app, and check that the coin count is saved. Verify music and effects, puzzles, growth, and the parent PIN and print preview. Rotate during a puzzle and check that the controls remain visible and the order remains in progress. On Android, press Back through a Settings subpage, a puzzle, a friend snapshot and a main screen. Also try saving after installing an app update.
5. To move an existing browser town into the installed app, export its save code in **Settings → Export or import town**. Open the same Settings page in the app, paste the code, check it and confirm replacement. Set a new parent PIN in the app.

## Google Play

- [ ] Create a Google Play Console developer account. Choose Personal or Organization based on who will publish. Review the distribution agreement and registration fee, and complete identity and Android device verification as prompted. [Google Play account setup](https://support.google.com/googleplay/android-developer/answer/6112435)
- [ ] If the personal account was created after 13 November 2023, run a closed test with at least 12 testers continuously opted in for 14 days. Collect feedback and fix issues during that period. Apply for production access from the Play Console dashboard when eligible. [Google Play closed testing](https://support.google.com/googleplay/android-developer/answer/14151465)
- [ ] Complete Target Audience and Content with the app’s real audience, then review the Families Policies because the game includes children in its audience. Review child-directed content, permitted permissions and SDKs, identifiers and data handling, and disclosure requirements. Describe the manual, read-only town visit codes to reviewers so they can assess the relevant Families provisions. Complete the content rating, ads declaration, Data safety form, and public privacy-policy URL. [Google Play Families Policies](https://support.google.com/googleplay/android-developer/answer/9893335), [Data safety form](https://support.google.com/googleplay/android-developer/answer/10787469)

## Apple App Store

- [ ] Enrol the publisher in the Apple Developer Program with two-factor authentication. Choose an individual or organization account and complete Apple’s identity and membership steps. Create the app record in App Store Connect and configure signing. [Apple Developer Program enrolment](https://developer.apple.com/programs/enroll/)
- [ ] Complete the age-rating questions. Review whether Made for Kids fits the actual 6–17 design. Apple’s Kids Category bands are 5 and under, 6–8, and 9–11. If using it, verify the parental gates around links out of the app or purchases, the rules on third-party analytics and advertising, and the naming and metadata requirements. Describe the offline visit codes and show how reviewers can open the PIN-gated report. [Apple Kids Category](https://developer.apple.com/kids/), [Apple age ratings](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating), [App Review Guidelines §§1.3, 2.3.8 and 5.1.4](https://developer.apple.com/app-store/review/guidelines/)
- [ ] Complete App Privacy based on the exact package uploaded. Add screenshots, a support URL and a public privacy-policy URL. Test iPhone and iPad layouts through TestFlight before submitting. [App Store privacy disclosures](https://developer.apple.com/app-store/app-privacy-details/)

## Privacy and children’s data

- [ ] Approve the [privacy policy draft](privacy.html). Update the shared policy text in `src/components/PrivacyPolicy.tsx` with the publisher’s privacy contact and release date, and publish the final copy at a stable public HTTPS address. Reflect the actual distribution build in both stores’ disclosures. The installed app contains no account, analytics, ads or save service. The browser version’s host receives ordinary web requests. Sharing a code or printing a report is a choice made on the device.
- [ ] For distribution in India, review the Digital Personal Data Protection Act, 2023 and the Digital Personal Data Protection Rules, 2025 with a qualified adviser. The Act defines children as under 18. Where the child-data provisions apply, obtain verifiable parental or lawful-guardian consent before processing their personal data and follow the restrictions on harmful processing, tracking, behavioural monitoring and targeted advertising. The Gazette gives section 9 an 18-month commencement period from publication of the 13 November 2025 notification. Verify the effective date, Rule 10 and any later notifications or applicable exceptions before release. [India Code Act](https://www.indiacode.nic.in/indiacode/handle/123456789/22037?view_type=browse), [MeitY commencement notification](https://www.meity.gov.in/static/uploads/2025/11/c56ceae6c383460ca69577428d36828b.pdf), [Digital Personal Data Protection Rules, 2025](https://upload.indiacode.nic.in/showfile?actid=AC_CEN_45_0_00003_2023-22_1763464807080&filename=dpdprules2025.pdf&type=rule)
- [ ] Treat accounts, leaderboards, cloud saves and live friend towns as future work. Plan a server, data minimisation and deletion, a legal and store-policy review, and verifiable parental consent where required before processing children’s personal data. The current parent PIN controls access to a local report. Legal consent requires a separate verification process.
